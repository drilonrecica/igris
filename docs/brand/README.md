# igris brand

The mark is a shadow knight's helm: black armor, glowing cyan seams and visor, and a red plume.

## Files

| File | Use |
|---|---|
| `igris-logo-dark.svg` / `igris-logo-light.svg` | Helm and wordmark, for dark and light backgrounds (README header) |
| `igris-mark-dark.svg` / `igris-mark-light.svg` | Helm only, 48px and up |
| `igris-mark-dark-512.png` / `igris-mark-light-512.png` | Helm as PNG, transparent background |
| `igris-icon.svg`, `igris-icon-{16,32,48,180,512}.png` | Visor icon on a black tile, 32px and below: favicon, avatar, app icon |
| `favicon.ico` | 16, 32 and 48px icon |

Below 48px the helm loses its detail, so use the icon instead.

## Colors

| Name | Hex | Role |
|---|---|---|
| Abyss | `#05070F` | Armor, darkest background |
| Night | `#0B1E46` | Main background |
| Deep | `#123A7A` | Gradients, raised surfaces |
| Glow | `#3CC8FF` | Seams, visor, active state |
| Glow core | `#B8F0FF` | Hot center of the visor |
| Plume | `#E3172B` | The plume, and the red `i` in the wordmark |
| Snow | `#EAF4FF` | Text on dark backgrounds |

On light backgrounds the seams use `#0A86C8` and the visor `#0A9BE6`, so they keep their contrast.

Rules:
- Cyan is the working accent. Red appears once per mark and is never used as a fill on the armor.
- Never recolor the plume, and never use the helm without it.

## Wordmark

The wordmark is lowercase `igris` in Chakra Petch Bold, with the second `i` in plume red. In the SVGs the letters are converted to outlines, so they don't need the font installed. Chakra Petch is licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).

Tagline: *Arise.* One task, one fresh session, the right rank.
