**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v0.1.1 is the result of running v0.1.0 for real: on plans from other projects, from a phone over SSH, with notifications on a phone, and through `igris adapt` on two messy plans. Everything it found is fixed here, each with a regression test. Upgrading is safe: no config keys, flags or file formats changed, and every plan that was valid stays valid.

## Highlights

- **No more lost tasks in new project folders.** In a folder Claude Code hasn't seen before, it first asks whether to trust the folder. igris held the task until that question was answered, but two things could still lose it: Claude Code draws its input box a moment before it takes input, so a task sent right after you accepted could vanish; and quitting igris while the question was open forgot the task. Both left Claude at an empty prompt. igris now waits until Claude Code really takes input, and keeps the held task in `.igris/state.json` across restarts.
- **Dependencies under another column name are no longer ignored silently.** A plan with a `Depends`, `Depends on` or `Requires` column (and no `[columns]` alias) was valid, but igris read it as an extra column, so the plan ran with no dependencies at all. `igris check` and `igris arise` now warn and show the one-line alias.
- **Notifications you can act on.** `task_done` is actually sent now (it was accepted in `events` but never raised). "Needs you" says why — waiting for a permission or an answer, idle without `igris done`, a skip request. Task titles arrive without markdown, and `igris notify test` sends seven distinguishable samples that say what a real one looks like.
- **Clearer plan errors.** Common status words get a hint (`dropped` → did you mean skipped?), so do cells wrapped in markdown (`` `M0-01` ``, `✅ Done`, `**Opus**`), `###` sub-headings that should be phases, and tables with a `State` column instead of `Status`.
- **Finished tasks need no Model.** A `done` or `skipped` agent task may have Model `—`: igris never starts a session for it. Set it back to `ready` and `igris check` asks for a model again.
- **For contributors:** `CONTRIBUTING.md`, `SECURITY.md` with private vulnerability reporting, and issue and pull request templates.

## Upgrade

```sh
go install github.com/drilonrecica/igris/cmd/igris@v0.1.1
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH`:

```sh
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_0.1.1_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

A run interrupted under v0.1.0 resumes normally under v0.1.1. Run `igris check` once on your plan: if it now warns about a dependency column, add the alias it shows to `igris.toml`.

## Known limitations

- herdr only; a tmux backend is planned.
- Linux and macOS only.
- Artifacts are not signed (SHA-256 checksums only).
- No Homebrew tap yet.
