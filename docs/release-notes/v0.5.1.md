**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v0.5.1 is a small patch for v0.5.0: a first prompt that sometimes stays unsubmitted, blank rows in the live tail, `report` help and completion, a second Ctrl-C that didn't always exit, an external interrupt that could hang the screen, and a huge or odd run log that could stall igris. No change to the plan format, config keys or file formats.

## Fixed

- **A pasted prompt gets submitted.** Rarely, Claude Code shows a session's first prompt in its input box but never submits it. When the session sits idle 15 s and its hooks never saw the prompt submitted, igris presses Enter once in the pane and says `the prompt didn't seem submitted; sent Enter once` in the feed. It never re-sends the prompt text; if that doesn't help, **Needs you** follows as before. Works in tmux and herdr.
- **No blank rows in the live tail.** A line Claude Code pads to the pane's width, such as the right-aligned `◐ medium · /effort`, now shows its text instead of a blank row ending in `…`.
- **`igris report` help and completion.** `igris report -h` and `igris history -h` show the `RUN` argument, and bash, zsh and fish complete run IDs after `igris report`, newest first.
- **A second Ctrl-C quits.** While igris winds down after a run (from `igris arise` or home), it prints `stopping… (Ctrl-C again to quit now)` and another Ctrl-C exits at once; `igris adapt` and `igris notify test` exit on a second Ctrl-C too.
- **`kill` no longer hangs the screen.** A SIGINT or SIGTERM sent from outside (`kill -INT <pid>`, `kill <pid>`) could leave the home screen, the run view or the `adapt` review frozen on the alternate screen. igris now handles both signals itself, and the screen always closes.
- **A huge or odd run log can't stall igris.** `igris history`, `igris report`, run-ID completion and the home screen read only the last 16 MiB of `.igris/runs.jsonl` (saying so when the log is larger), and a FIFO in its place is an error instead of a hang.

## Upgrade

```sh
brew upgrade igris
go install github.com/drilonrecica/igris/cmd/igris@v0.5.1
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH`. A run interrupted under v0.5.0 resumes normally.
