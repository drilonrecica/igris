**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

igris 1.3 adds to 1.2 and breaks nothing: Claude can now write your plan. Plans, `igris.toml` and scripts written for 1.0 to 1.2 need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.3.0/docs/compatibility.md)).

## What's new

- **`igris draft`.** A session writes a plan proposal, you review it as for `igris adapt`, and only Accept writes your plan. Four sources:
  - `igris draft goal [TEXT]`: the session interviews you in its pane, then drafts. Its summary goes in `## Draft notes`, and `M0-01` is your task of writing the spec.
  - `igris draft spec FILE`: from a spec or PRD in the project (at most 1 MiB). Requirements it leaves out are listed.
  - `igris draft import FILE`: from a GitHub issues JSON export, or a Linear or Jira CSV export. igris parses the export itself and never contacts those services; closed issues become `done` rows.
  - `igris draft extend [TEXT]`: new phases or tasks for your current plan, also a split one, with every other byte kept and a backup in `.igris/draft/`.
  
  [Draft a plan](https://drilonrecica.github.io/igris/docs/draft.html).
- **Ranks are suggestions.** A draft's Model cells are guesses; ones the session is unsure of stay `?`, the review counts them, and a proposal that fails `check` needs a second confirmation.
- **Home: Draft… (`D`).** The same four sources from home, with progress, Open session and the review. GET STARTED offers it next to Plan from template….
- `[draft] model` (`sonnet` or `opus`, default `opus`), `--model`, `--plan` and `--format` flags, and a `.igris/draft/` directory. All additive.

`goal`, `spec` and `import` write a plan only where none is (use `--plan PATH` or `extend` otherwise). The session runs in `manual` mode because a spec or an export is text igris didn't write: [SPEC §9.1](https://github.com/drilonrecica/igris/blob/v1.3.0/SPEC.md).

## Upgrade

From 1.2, `igris update` does it for you. From 1.0 or 1.1 there is nothing to do but install. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.3.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.3.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.3.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
