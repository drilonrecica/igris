**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

igris 1.13 makes `igris hub` start with no flags and corrects the firewall advice for Tailscale. It only adds: plans, `igris.toml`, `--json`, the run log, the webhook payload and your templates need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.13.0/docs/compatibility.md)).

## What's new

- **A bare `igris hub` picks its address.** `--http` is optional. The hub listens on this machine's Tailscale address (the first in `100.64.0.0/10`), else on `127.0.0.1` with a line saying how to reach it from elsewhere, and always on port 7780, so a bookmark and a pairing keep working. A line before the QR code says what was chosen. If 7780 is held by a hub already running there, igris says so and exits 0; if by anything else, it says to pass `--http` and exits 1. `igris hub token` prints the same URL, and accepts `--http`.
- **Off a terminal, the hub takes all runs.** Without PATH and not on a terminal it exited 2 before; it now takes all runs, as `--all` does, and says so.
- **The firewall advice for Tailscale.** On Fedora, trust Tailscale's ranges (`firewall-cmd --permanent --zone=trusted --add-source=100.64.0.0/10 --add-source=fd7a:115c:a1e0::/48`) instead of opening `7777/tcp`: it covers the hub's port too, survives reboots and doesn't open the port to your LAN. The docs also say why `--add-interface=tailscale0` doesn't stick, and what `ufw` and `nftables` users do.

## Upgrade

Install the new igris and you are done: nothing in your plan, `igris.toml`, scripts or `.igris/` needs to change, and a run interrupted under 1.12 resumes. `igris update` does it for you. Stop a run (`igris stop`) before you update the igris that is hosting it. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

One thing to know: `igris hub` without `--http` is a usage error in igris 1.12 and earlier, so a script that relied on that (or on exit code 2 off a terminal) sees a hub start. Pass `--http ADDR:PORT` to keep the old behavior.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.13.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.13.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.13.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.

The editor extension is unchanged in 1.13 and keeps its version, 1.9.0. It isn't in the Marketplace or Open VSX: install it with `code --install-extension igris-1.9.0.vsix`, the file attached below (Cursor, Kiro, Antigravity and Windsurf take the same file).
