**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

This is the first release. It runs on Linux and macOS and needs [herdr](https://herdr.dev).

## Highlights

- **One task, one fresh session, the right rank.** `igris arise M0` takes the next ready task, starts Claude Code with that task's model (`sonnet`, `opus`, `fable`, …) and moves on only when the task is really done. It never picks a model itself and never runs a task on a more expensive one.
- **Your plan stays yours.** Igris changes only Status cells, byte for byte. `igris check` validates the plan and `igris status` shows what's ready and what's blocked. `igris adapt` converts a plan in another format, and you review the diff before anything is replaced.
- **Stops when it needs you.** Questions, plans to approve, stalled sessions, verify failures and user tasks pause the run and notify you through herdr toasts, ntfy or Discord.
- **Verify and commit.** `verify` runs on every `done` and failures go back into the same session. Commits are `ask`, `auto` or `never`.
- **A TUI that works from a phone.** Mouse and keyboard, choice dialogs, and a single-column layout for small terminals over SSH. `--no-tui` is there for scripts.
- **Resumable.** Quit any time; `igris arise` reattaches to the running session or continues where it left off.
- **Guardrails.** Skip-permissions needs a typed confirmation every run, igris warns when `ANTHROPIC_API_KEY` would bill the API, and sessions are treated as untrusted (config snapshot, unexpected plan edits pause the run, escape sequences stripped).

## Requirements

- Claude Code, logged in the way you normally use it
- herdr, ideally with `herdr integration install claude`
- git (recommended)

## Install

```sh
go install github.com/drilonrecica/igris/cmd/igris@v0.1.0
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH`:

```sh
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_0.1.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

Then, in a herdr pane in your project:

```sh
igris init && igris check && igris arise M0
```

## Known limitations

- herdr only; a tmux backend is planned.
- Artifacts are not signed (SHA-256 checksums only).
- No Homebrew tap yet.
