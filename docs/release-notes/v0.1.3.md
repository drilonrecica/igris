**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v0.1.3 brings igris to Windows through WSL2. It also fixes one bug that plans saved by Windows editors could hit. Upgrading is safe: no flags or file formats changed, and every config and plan that worked before still works.

## Highlights

- **Windows through WSL2.** The README has a new [Windows (WSL2)](https://github.com/drilonrecica/igris#windows-wsl2) section. In short: install herdr, Claude Code and igris *inside* WSL (use the `linux_amd64` archive), and keep your project on the Linux filesystem rather than under `/mnt/c`. A native Windows build is not planned.
- **Tested by simulation, not yet on real WSL2.** No Windows machine was available for this release. Instead, the herdr smoke test was run on Linux under the conditions WSL users have: a project path with spaces (`John Doe/my project`), the plan a symlink onto another filesystem, `tasks.md` and `igris.toml` saved with a byte order mark and CRLF line endings, and `core.autocrlf` on. It passed after the fix below. [`docs/check-wsl.md`](https://github.com/drilonrecica/igris/blob/master/docs/check-wsl.md) is the checklist for a real WSL2 machine. If you run igris on WSL2, an issue saying how it went (good or bad) is very welcome.
- **Fix: plans with a byte order mark.** Some Windows editors start UTF-8 files with a byte order mark (BOM). If the plan's first line was a `## Phase` heading, the BOM hid it, and `igris check` reported "task table outside a phase". igris now ignores a leading BOM when reading the plan, and keeps it when it writes a Status cell, so the file stays exactly as your editor saved it.

## Upgrade

```sh
go install github.com/drilonrecica/igris/cmd/igris@v0.1.3
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH` (on Windows, do this inside WSL with the linux archive):

```sh
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_0.1.3_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

A run interrupted under v0.1.2 resumes normally under v0.1.3.

## Known limitations

- herdr only; a tmux backend is planned.
- Linux and macOS; Windows through WSL2 only, and WSL2 is not yet verified on a real Windows machine.
- Artifacts are not signed (SHA-256 checksums only).
- No Homebrew tap yet.
