**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v1.2.1 is a security patch for v1.2.0: the same igris, built with Go 1.27.3 instead of 1.27.2. No code change, and no change to the plan format, config keys, CLI or file formats.

## Security

- **Built with Go 1.27.3**, which fixes [GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809): Go 1.27.2's `crypto/x509` didn't reject a set of compromised intermediate certificates on systems whose trust store doesn't already distrust them. igris makes HTTPS requests only to your notification endpoints and, when you ask, to GitHub's releases API (`igris update`). Both check certificates with that code. The risk is low, since most systems' trust stores already handle these certificates, but you should update.

## Upgrade

From 1.2.0, run `igris update` (or press `u` on home), then quit and start igris again. From 1.0 or 1.1 there is nothing to do but install; see the [1.2.0 release notes](https://github.com/drilonrecica/igris/releases/tag/v1.2.0) for what 1.2 adds.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.2.1`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.2.1/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.2.1_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
