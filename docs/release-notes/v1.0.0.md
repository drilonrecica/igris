**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

igris 1.0 is a promise: from here until 2.0, what you build on igris keeps working.

## What 1.0 promises

These keep working unchanged ([SPEC §19](https://github.com/drilonrecica/igris/blob/v1.0.0/SPEC.md#19-compatibility), [`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.0.0/docs/compatibility.md)). 1.x may add to them (new optional plan columns, config keys with defaults, commands, flags, JSON fields, run-log events, template variables) and never removes or changes them. Something deprecated in 1.x keeps working, with a warning, until 2.0.

- **The plan format**, format 1: [`docs/plan-format.md`](https://github.com/drilonrecica/igris/blob/v1.0.0/docs/plan-format.md). A plan may say `<!-- igris:format 1 -->`; it never has to.
- **`igris.toml`**: keys, defaults and validation.
- **The CLI**: commands, flags, arguments, and exit codes (`0` success, `1` failure, `2` usage error, `3`–`9` reserved).
- **`--json`** of `check`, `phases`, `status`, `history`, `report` and `doctor`, with schemas in [`docs/json/`](https://github.com/drilonrecica/igris/tree/v1.0.0/docs/json).
- **`igris done`, `skip` and `reset`** and the signal files they write; **`.igris/`** with `state.json` (version 3) and the run log (`"v": 1`).
- **Template variables**, the **generic webhook** (payload, `X-Igris-Event`, `X-Igris-Signature`) and the **task-hook environment** (`IGRIS_*`).

Not promised: the TUI, the default prompt's wording, text output (use `--json`), and igris's Go packages.

A compatibility suite keeps the promise honest: the configs, plans and signal files every release from 0.1.0 to 0.6.0 wrote, plus the state files and run logs of each format, are checked on every change.

## What's in 1.0.0

1.0.0 is [1.0.0-rc.2](https://github.com/drilonrecica/igris/releases/tag/v1.0.0-rc.2) with no further code changes. Across the two candidates since 0.6.0:

- The 1.0 contract above, written down and tested; `--json` and exit codes settled (`"v": 1` on every output; see the changelog's Migration notes).
- `claude.command` removed from `igris.toml`; **`igris config migrate`** deletes it.
- The final security review's fixes: reattach bound to the task's own pane, a changed `igris.toml` confirmed before use, stricter config validation, bounded reads, broader text cleaning. [`docs/threat-model.md`](https://github.com/drilonrecica/igris/blob/v1.0.0/docs/threat-model.md).
- Docs pages on the project site, and a config reference generated from the code.

Soaked on real projects on Linux and macOS, on herdr, driven over Termius. tmux is covered by the backend conformance suite rather than a hand soak, and rc.2's reattach fixes by regression tests.

## Upgrade

From 0.x: install 1.0.0, then run **`igris config migrate`** once in each project. Plans need nothing. If you read `--json` in scripts or test exit codes, see the 1.0.0-rc.1 notes in the [changelog](https://github.com/drilonrecica/igris/blob/v1.0.0/CHANGELOG.md#100-rc1---2026-10-14). If you ran an rc, you need nothing. The [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html) has the whole path.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.0.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.0.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.0.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.

See [CHANGELOG.md](https://github.com/drilonrecica/igris/blob/v1.0.0/CHANGELOG.md) for every change and the [README](https://github.com/drilonrecica/igris#readme) for the full guide.
