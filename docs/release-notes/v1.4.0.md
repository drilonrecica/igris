**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

igris 1.4 adds to 1.2 and breaks nothing: Claude can now write your plan, and a run survives a closed terminal. There is no 1.3 release; both ship here. Plans, `igris.toml` and scripts written for 1.0 to 1.2 need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.4.0/docs/compatibility.md)).

## What's new

- **Detach and attach.** `igris arise` now starts the run in a background `igris serve` and attaches to it. Close the terminal, lose the ssh connection or put the laptop to sleep and the run goes on; `igris attach` (or bare `igris`, whose home shows **Attach** first) opens it again from any terminal, your phone over ssh included. Several terminals can be attached at once and the first answer to a question wins. A lost connection shows `reconnecting…` and returns with a fresh snapshot. [Detach and attach](https://drilonrecica.github.io/igris/docs/detach-attach.html).
  - `q` in the run view now asks **Detach** (focused) · Stop run · Cancel. Ctrl-C and a closed terminal detach without asking.
  - `igris serve [PHASE]` runs a phase headless (outside herdr and tmux, in a detached tmux session `igris-<project>`), and `igris stop` stops the live run from a script.
  - `arise --no-tui` and `--dry-run` stay in one process, as before. The skip-permissions phrase is still typed every run; it never travels as a flag.
  - After `igris update` during a run, the attached view says `served by igris X.Y.Z`: the run keeps that igris until it ends.
- **`igris draft`.** A session writes a plan proposal, you review it as for `igris adapt`, and only Accept writes your plan. Four sources:
  - `igris draft goal [TEXT]`: the session interviews you in its pane, then drafts. Its summary goes in `## Draft notes`, and `M0-01` is your task of writing the spec.
  - `igris draft spec FILE`: from a spec or PRD in the project (at most 1 MiB). Requirements it leaves out are listed.
  - `igris draft import FILE`: from a GitHub issues JSON export, or a Linear or Jira CSV export. igris parses the export itself and never contacts those services; closed issues become `done` rows.
  - `igris draft extend [TEXT]`: new phases or tasks for your current plan, also a split one, with every other byte kept and a backup in `.igris/draft/`.

  [Draft a plan](https://drilonrecica.github.io/igris/docs/draft.html).
- **Ranks are suggestions.** A draft's Model cells are guesses; ones the session is unsure of stay `?`, the review counts them, and a proposal that fails `check` needs a second confirmation.
- **Home: Draft… (`D`).** The same four sources from home, with progress, Open session and the review.
- `[draft] model` (`sonnet` or `opus`, default `opus`), `--model`, `--plan` and `--format` flags, the socket `.igris/igris.sock`, `.igris/serve.log` and `.igris/draft/`. All additive; `state.json` stays version 3.

`goal`, `spec` and `import` write a plan only where none is (use `--plan PATH` or `extend` otherwise). The session runs in `manual` mode because a spec or an export is text igris didn't write: [SPEC §9.1](https://github.com/drilonrecica/igris/blob/v1.4.0/SPEC.md).

The run's socket is a new boundary: only your user reaches it, every message is bounded and checked, and skip-permissions mode still needs the typed phrase. Any process of your user can drive a run over it, as it can already edit the plan: [`docs/threat-model.md`](https://github.com/drilonrecica/igris/blob/v1.4.0/docs/threat-model.md).

## Upgrade

From 1.0 to 1.2 there is nothing to do but install; `igris update` does it for you from 1.2. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html). Stop a run (`igris stop`) before you update the igris that is hosting it, or it keeps the old one until it ends.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.4.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.4.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.4.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
