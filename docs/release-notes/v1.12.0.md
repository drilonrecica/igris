**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

igris 1.12 makes the run view easier to read at one look, and retires the old web UI cookie. It only adds, apart from that cookie: plans, `igris.toml`, `--json`, the run log, the webhook payload and your templates need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.12.0/docs/compatibility.md)).

## What's new

- **The mode on a task row, where it differs.** A task whose next session would run in a mode other than the run's (the plan's Mode cell, or `M`) ends its row in that mode, `plan` for example. A skip-permissions mode (`yolo`, `plan:yolo`) always shows, in Ember. Done and skipped rows show none.
- **The run view on a small terminal.** TASKS is only as tall as its rows; the card that needs you comes first and keeps its whole body while other active tasks shrink to a line each; the bar is one row (`[o Open session] [p Pause] [x Stop…] [? More]`; every other key still works and `?` lists it); a quiet log lends its rows to the session's last lines. One set of rules at every size.
- **The old cookie retires.** The web UI's `igris_token` is no longer accepted (1.11 moved it to `igris_token_<h>`).
- **Fixed: Start anyway from the terminal UI.** During a usage hold or outside working hours, `a` in the run view was refused (`limit takes text start`) since 1.8; it now starts the task.

## Upgrade

Install the new igris and you are done: nothing in your plan, `igris.toml`, scripts or `.igris/` needs to change, and a run interrupted under 1.11 resumes. `igris update` does it for you. Stop a run (`igris stop`) before you update the igris that is hosting it. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

One thing to know: a phone or browser paired under 1.9 or earlier that you didn't open during 1.11 still holds only the old cookie `igris_token`, which igris 1.12 refuses. Pair it again with `igris serve token`. A phone opened under 1.11 is unaffected.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.12.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.12.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.12.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.

The editor extension is unchanged in 1.12 and keeps its version, 1.9.0. It isn't in the Marketplace or Open VSX: install it with `code --install-extension igris-1.9.0.vsix`, the file attached below (Cursor, Kiro, Antigravity and Windsurf take the same file).

See [CHANGELOG.md](https://github.com/drilonrecica/igris/blob/v1.12.0/CHANGELOG.md) for every change and the [README](https://github.com/drilonrecica/igris#readme) for the full guide.
