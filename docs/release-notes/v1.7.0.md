**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

igris 1.7 gives the terminal UI, the web UI and the command line one design language and breaks nothing that 1.x promises: plans, `igris.toml`, `--json`, the run log and the webhook payload need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.7.0/docs/compatibility.md)). The TUI's keys and mode picker did move; see "Keys that moved" below.

## What's new

- **One design language, written down.** [`docs/design.md`](https://github.com/drilonrecica/igris/blob/v1.7.0/docs/design.md): seven rules, one glyph table (`✓ ● ! · ⨯ – ▲ ✗ ◌`), the status words, and **red means you**: plume red only for Needs you and skip permissions, **Ember** for every warning. Nothing is shown by color alone, `NO_COLOR` is honored.
- **A run screen that leads with what needs you.** Panes sized by content, a Needs-you banner with the right card selected, **Arise.** at the start and an end-of-run summary with the helm: outcome, tasks done, skipped and failed, wall time, usage, the next step.
- **Home, denser.** A run elsewhere that needs you shows on home with Attach; GET STARTED says what to do on each step.
- **A phone page that keeps Stop in reach.** The Needs-you sheet folds to a peek strip, more questions are a stepper, every page carries the brand and the next step, and light theme text meets AA contrast.
- **A command line that speaks the same words.** One table style, the TUI's glyphs in `status`, `history` and `--dry-run`, grouped help, `next:` hints, a `doctor` summary line and "did you mean" for a mistyped command. `--json` is untouched.
- **Notifications lead with the status word.** `! Needs you` is the only high-priority kind; the webhook payload and your templates are unchanged.
- **`igris report` has its Tokens column**, as SPEC §14 has promised since 1.1.
- A new demo GIF, screenshots and a README rewritten for 1.7.
- Fixed: approving a plan in igris no longer sends a false Needs you, the phone's live tail shows the newest lines, home notices a run whose igris died without cleaning up, and a run whose igris was killed reads as interrupted, not failed.

## Keys that moved

The TUI isn't covered by the compatibility promise, so 1.7 gave every key one meaning on every screen:

- `a` is the one way into the run on home (Arise…, Resume… or Attach); `t` is Details everywhere.
- `q` leaves the screen you are on (Quit on home); `ctrl+c` quits igris from anywhere, and a run `igris serve` hosts goes on.
- The adapt and draft review: `A` accepts, `x` rejects.
- The mode picker lists plan, auto, accept, manual and default first; **More modes…** has plan:default, plan:accept, plan:auto, yolo and plan:yolo. No mode is gone, and yolo still needs the typed phrase.
- Cancel is the last option of a dialog, and `esc` picks it. `?` lists every binding of the screen.

## Upgrade

Install the new igris and you are done: nothing in your plan, `igris.toml`, scripts or `.igris/` needs to change, and a run interrupted under 1.6 resumes. `igris update` does it for you. Stop a run (`igris stop`) before you update the igris that is hosting it, or it keeps the old one until it ends. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.7.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.7.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.7.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
