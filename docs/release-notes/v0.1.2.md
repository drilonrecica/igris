**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v0.1.2 is about robustness. igris now tells you when the Claude Code or herdr on your machine isn't one it was verified with. The parser and the plan writer, the two parts that touch your plan, are now fuzzed, and error messages say what to do next. Upgrading is safe: no config keys, flags or file formats changed, and every plan that was valid stays valid.

## Highlights

- **Version warnings.** Claude Code and herdr change often, and igris depends on their flags and output. `igris check` and `igris arise` now run `claude --version` and `herdr --version`. They warn if a tool is missing, older than the oldest version igris is verified with (Claude Code 2.1.291, herdr 0.9.1), or a newer major version than the newest one re-verified. Newer minor and patch versions don't warn. It is only ever a warning: igris never refuses to run because of a version.
- **Your plan is safe, now with stronger evidence.** igris writes your plan in one place only: a task's Status cell. That promise is now a fuzz property. For arbitrary plans (CRLF, no trailing newline, escaped pipes, backticks, fenced blocks that look like tables, non-ASCII, very long cells), a status change leaves every other byte of the file exactly as it was. Each target ran for 10 minutes without a finding. The parser, the config loader and the signal reader are fuzzed too: malformed input gives an error, never a crash.
- **Errors you can act on.** The common failures now end with the next step:
  - herdr not installed;
  - no plan file;
  - Claude Code failing to start in a tab;
  - a failing `git commit` hook;
  - a stale lock;
  - a mistyped task ID;
  - a usage error.

  `igris done` run outside a live run says the signal is kept for the next `igris arise`.
- **For contributors:** `make fuzz` runs every fuzz target, and `docs/reverify.md` re-checks the Claude Code flags and herdr JSON shapes igris relies on. It ran clean against Claude Code 2.1.292 and herdr 0.9.1.

## Upgrade

```sh
go install github.com/drilonrecica/igris/cmd/igris@v0.1.2
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH`:

```sh
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_0.1.2_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

A run interrupted under v0.1.1 resumes normally under v0.1.2. Run `igris check` once: if it warns about your Claude Code or herdr version, that tells you what to update.

## Known limitations

- herdr only; a tmux backend is planned.
- Linux and macOS only.
- Artifacts are not signed (SHA-256 checksums only).
- No Homebrew tap yet.
