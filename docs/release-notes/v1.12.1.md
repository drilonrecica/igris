**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

v1.12.1 is a patch for v1.12.0 with one fix. No change to the plan format, `igris.toml`, the CLI, `--json`, the run log or protocol 1.

## Fixed

- **The plan dialog now closes when you answer the plan in the session's pane.** When a task in plan mode presents its plan, igris shows it for approval, and Claude Code shows its own dialog in the session's pane. If you approved the plan or typed feedback in the pane, Claude Code (2.1.322) left igris's waiting hook running, so the plan stayed open in the terminal UI, the web UI, the hub and the editor extension, and the hook waited until `approve_timeout` (30 minutes by default). Now the plan closes as soon as the session goes on after it, and igris tells the waiting hook to end. A plan still waiting at Claude Code's prompt stays open, and approving or rejecting from igris works as before.

## Upgrade

From 1.12.0, run `igris update` (or press `u` on home), then quit and start igris again. Stop a run (`igris stop`) before you update the igris that is hosting it. From an earlier release, see the [1.12.0 release notes](https://github.com/drilonrecica/igris/releases/tag/v1.12.0) for what 1.12 adds.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.12.1`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.12.1/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.12.1_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.

The editor extension is unchanged in 1.12.1 and keeps its version, 1.9.0: the fix is in igris, and the extension closes the plan from the same event. It isn't in the Marketplace or Open VSX: install it with `code --install-extension igris-1.9.0.vsix`, the file attached below (Cursor, Kiro, Antigravity and Windsurf take the same file).
