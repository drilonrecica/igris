**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

igris 1.2 adds to 1.1 and breaks nothing: open a Claude Code session of your own next to a run, split a long plan across files, and start a project from a plan template. Plans, `igris.toml` and scripts written for 1.0 or 1.1 need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.2.0/docs/compatibility.md)).

## What's new

- **Side sessions.** Press `S` on home or in the run view for a session of your own, in a pane next to the run's: blank, about a task, or about an igris problem, with the model and mode you pick (never skip-permissions). It is not a task: no attempt, no Status, no Needs you. During a run it shares the tree (with a warning) or gets a worktree of its own, and a plan edit from it holds the run like any other. Quitting igris leaves side sessions open and the next start finds them again. Their tokens show in a table of their own in `igris usage`. [Side sessions](https://drilonrecica.github.io/igris/docs/side-sessions.html).
- **Split plans.** `<!-- igris:include phases/v2.md -->` in a plan that declares `<!-- igris:format 2 -->` pulls another file's phases in. `check` and the rest read it as one plan and name the file of every problem; `arise` writes each Status in the file its row is in, and an edit to any file holds the run. **A split plan needs igris 1.2 on every machine that runs it**: 1.0 and 1.1 refuse it instead of running part of it. [Split plans](https://drilonrecica.github.io/igris/docs/split-plans.html).
- **Plan templates.** `igris init --template go-cli|web-app|library` writes a starter plan with phases, gates and suggested ranks (review the Model column first). Home's **Example plan** is now **Plan from template…**. [Plan templates](https://drilonrecica.github.io/igris/docs/templates.html).
- **`manual` mode.** `manual` passes `--permission-mode manual`, so every permission prompt goes to you whatever Claude Code's own default is. `default` still passes no flag and follows Claude Code's own default, which can be auto if you opted into auto as Claude Code's default: use `manual` if you want every prompt. During a run, a side session in the shared tree now preselects `manual`.
- **igris in PATH.** Sessions run `igris done` with the `igris` in your `PATH`. `check`, `arise`, `doctor` and home now warn when that is missing or another igris than the one you run, with its path and version.
- **Check for updates.** `igris update` (or `u` on home) asks GitHub for the latest release and, after you say yes, updates igris with whatever installed it: `brew upgrade igris`, or `go install …@vX.Y.Z` into the same directory; an archive install gets the download and verify steps. `igris update --check` only looks. igris contacts GitHub only when you ask, never on its own, and never replaces its own binary: quit and start igris again afterwards. [Updating igris](https://drilonrecica.github.io/igris/docs/install.html#updating-igris).
- **Usage fixes.** A task that ran on several models is counted under each, and a run with no usage data says why.
- `[side]` settings, `file` and `files` in `--json` output, a `side` array in `usage --json`, new run-log events (`side_opened`, `side_closed`, `side_usage`) and a `.igris/side/` directory. All additive.

A session can add an include or rewrite an included file like any plan edit (the run is held), and unset `IGRIS_SIDE` in a side session; `igris adapt` refuses a split plan; the update check uses only the release's tag from GitHub's answer and leaves the binary's integrity to Homebrew and Go: [`docs/threat-model.md`](https://github.com/drilonrecica/igris/blob/v1.2.0/docs/threat-model.md).

## Upgrade

From 1.0 or 1.1 there is nothing to do but install. From 1.2 on, `igris update` does it for you. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.2.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.2.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.2.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
