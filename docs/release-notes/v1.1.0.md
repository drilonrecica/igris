**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

igris 1.1 adds to 1.0 and breaks nothing: approve a plan-mode session's plan from igris, see the tokens each run and task used, and get told when a task ran on a model its rank doesn't name. Plans, `igris.toml` and scripts written for 1.0 need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.1.0/docs/compatibility.md)).

## What's new

- **Approve plans in igris.** A plan-mode session's plan opens in a dialog and the task is marked **needs you**: approve, reject with feedback, or answer in the pane. Whichever you answer first wins, and if you don't answer (or igris is gone) the plan waits in the pane as before. Every plan is kept under `.igris/plans/`, and the approved one goes into the commit body. `plan:default`, `plan:accept`, `plan:auto` and `plan:yolo` in a task's Mode name the mode it continues in after you approve; `plan:yolo` needs the typed skip-permissions confirmation, every run. New `[plan_mode]` settings: `then`, `approve_timeout`.
- **Token usage.** igris reads token counts and model ids (never messages) from each session's transcript and logs a `usage` line per attempt. The run card shows the current task's counter. These are tokens, never a cost. `[usage] enabled = false` turns it off.
- **`igris usage [RUN | --since D] [--json]`**: tokens by task, model and rank, the top consumers, the audit result and the last quota, for a run or across runs. `igris report` gains a Tokens column.
- **Rank audit.** A session whose main thread runs on another model than its rank resolves to marks the task **needs you** with `RANK MISMATCH`, sends a `rank_mismatch` notification (now a default event) and logs it, once per attempt. igris never stops or switches the session.
- **Subscription quota**, opt-in with `[usage] statusline = true`: your 5-hour and 7-day limits in the header and in `igris usage`. It replaces your status line in task panes, which is why it is off by default.
- **Parallelism report.** `igris phases` and `arise --dry-run` show each phase's critical path, width and the tasks that could run together. igris still runs one task at a time.
- New `--json` fields and a `usage` schema in [`docs/json/`](https://github.com/drilonrecica/igris/tree/v1.1.0/docs/json), new run-log events, and docs: [usage and plans](https://drilonrecica.github.io/igris/docs/usage.html).

A session could forge its transcript, `quota.json` or an approval of its own plan (it can write `.igris/` like everything else in the project), but never pick the mode a plan switches to: [`docs/threat-model.md`](https://github.com/drilonrecica/igris/blob/v1.1.0/docs/threat-model.md).

## Upgrade

From 1.0 there is nothing to do but install. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.1.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.1.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.1.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
