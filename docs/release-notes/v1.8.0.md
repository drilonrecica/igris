**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

igris 1.8 makes a long unattended run safer to leave, and only adds to 1.7: plans, `--json`, the run log, the webhook payload and your templates need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.8.0/docs/compatibility.md)).

## What's new

- **[Usage limits](https://drilonrecica.github.io/igris/docs/limits-and-budgets.html).** A session that hits a limit waits and continues at the reset; new tasks are held until then, with a countdown and one notification per episode. With `[usage] statusline = true` igris also holds before a hit, at `hold_at` (default 95%).
- **Budgets and a price estimate.** `[usage.budget]` for the run, a phase or a rank, in tokens or `$`: reaching one is Needs you (Raise, Continue, Stop). Nothing is stopped and no model is ever switched. Tokens come with `≈ $12.40` at embedded, dated API list prices, always labelled an estimate.
- **Where the time went.** `igris report` and `history` split time into agent, verify, needs-you and limit wait.
- **[A conflict resolver](https://drilonrecica.github.io/igris/docs/resolver.html).** `[parallel] on_conflict = "resolve"`: a task that doesn't integrate gets one resolver session, then one rerun, then Needs you. Verify runs on the integrated tree either way.
- **[Handoff notes](https://drilonrecica.github.io/igris/docs/handoff-notes.html).** A task's prompt carries the notes and approved plans of the tasks it depends on, bounded and cleaned. `dep_notes = false` turns it off.
- **Fewer interruptions.** `commit = "batch"` commits as it goes and asks once at the end (Undo keeps your changes); Commit all; notifications that say what waits and open the right question on your phone.
- Fixed: an offline `igris reset` no longer asks for the skip-permissions phrase.
- Fixed: a finished task's tokens show on its card while it waits for you, and `igris report` names the commit that landed on the branch for a task of a parallel phase.

## Upgrade

Install the new igris and you are done: nothing in your plan, `igris.toml`, scripts or `.igris/` needs to change, and a run interrupted under 1.7 resumes. The new keys and values are refused by igris 1.0–1.7, so finish a run before going back. `igris update` does it for you. Stop a run (`igris stop`) before you update the igris that is hosting it. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.8.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.8.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.8.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
