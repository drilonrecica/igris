**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side.

igris 1.5 adds to 1.4 and breaks nothing. A phase without the new marker runs one task at a time exactly as before; plans, `igris.toml` and scripts written for 1.0 to 1.4 need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.5.0/docs/compatibility.md)).

## What's new

- **Parallel phases.** Declare `<!-- igris:format 3 -->`, put `<!-- igris:parallel -->` under a phase heading, and the tasks of that phase that don't depend on each other run together, up to `[parallel] max` (default 2, at most 8; `igris arise --parallel N` for one run). [Parallel phases](https://drilonrecica.github.io/igris/docs/parallel-phases.html).
  - Each task works in its own git worktree and branch, from the run branch's head, with its own session and verify. `IGRIS_SLOT` (`0` to `max - 1`) lets your project offset ports and test databases.
  - A task that passes verify is committed, rebased onto the run branch, verified again on the merged tree and fast-forwarded in, in the order tasks finish. It is `done` only then, so dependents never start on code that isn't on the branch.
  - A task that doesn't merge (a conflict, or verify failing after the rebase) is run again from the start once; a second failure is Needs you with the details.
  - A `Group` column keeps tasks apart; `[parallel.ranks]` caps a rank (default `fable = 1`); tasks that need you, gates included, run alone. igris warns when two active tasks change the same file.
- **A run view for several tasks:** one card per active task (a switcher on a narrow terminal), one Needs-you queue in plan order, and notifications that say `2 tasks need you`.
- `state.json` version 4, the run-log events `integrated`, `integration_failed` and `overlap`, `[parallel]` and `[parallel.ranks]` in `igris.toml`, `--parallel` on `arise` and `serve`. All additive.

## What it costs

Parallel is faster on the clock, not cheaper, and not always safe. **Your limits burn N times faster** with N sessions. **Every worktree starts without build caches or `node_modules`**, so each task pays for its own install and cold build, with N times the disk. **A dependency your plan leaves unsaid becomes a conflict**, and the rerun does the work twice. Start with `max = 2` on a small, independent, well-gated phase; `igris phases` shows which tasks could run together.

Parallel changes no permission: skip-permissions mode still needs the typed phrase every run, and a session can still read and write the other tasks' worktrees as itself, which [`docs/threat-model.md`](https://github.com/drilonrecica/igris/blob/v1.5.0/docs/threat-model.md) lists as an accepted risk. igris 1.0 to 1.4 refuse a format-3 plan and `state.json` version 4, so finish a run before you go back to them.

## Upgrade

From 1.0 to 1.2 there is nothing to do but install; `igris update` does it for you from 1.2. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html). Stop a run (`igris stop`) before you update the igris that is hosting it, or it keeps the old one until it ends.

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.5.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.5.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.5.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.
