**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task.

v0.2.1 is a small patch for v0.2.0: two wording bugs in the home screen and history. No change to the plan format, config keys or file formats.

## Fixed

- **A completed run reads as done on home.** After a run whose phases all completed, the NOW card is `READY` with a `last run P1 completed` line and the action bar says **Arise…**, instead of `STOPPED` with **Resume**. A stopped run whose phases still have work stays `STOPPED`.
- **A running task reads "running".** In `igris history`, `--json` and the RUNNING card's `recent:` line, a task still being worked on in a live run shows `running`, not `unfinished`. `unfinished` is kept for tasks a run ended before they did.

## Upgrade

```sh
brew upgrade igris
go install github.com/drilonrecica/igris/cmd/igris@v0.2.1
```

Or download the archive for your platform below, check it against `checksums.txt`, and put the binary on your `PATH`. A run interrupted under v0.2.0 resumes normally.
