**igris** runs the tasks in your markdown project plan one at a time, each in a fresh Claude Code session, started with exactly the model your plan assigns to that task. Since 1.5, in a phase you mark parallel, it runs independent tasks side by side. Since 1.6 you can follow a run and answer its questions from your phone.

igris 1.9 puts igris in your editor, and only adds to 1.8: plans, `--json`, the run log, the webhook payload and your templates need no changes ([`docs/compatibility.md`](https://github.com/drilonrecica/igris/blob/v1.9.0/docs/compatibility.md)).

## What's new

- **[The Igris extension](https://drilonrecica.github.io/igris/docs/editor.html)** for VS Code (verified in 1.100; Cursor, Kiro, Antigravity and Windsurf take the same `.vsix` and are not yet tried) (`drilonrecica.igris`; not in the Marketplace or Open VSX for now: install the `igris-1.9.0.vsix` attached below with `code --install-extension`, or build it from the tag with `make vsix`). A client of `igris serve`: the plan's phases and tasks with the live run on top, the status word in the status bar, what needs you answered from a notification or a QuickPick, a task's commits or branch in the editor's diff, a CodeLens on the plan's rows, and each active task's session as a terminal tab, so you never handle tmux. **Igris: Set up** checks igris, Claude Code and tmux and starts a first run with one button. It needs igris 1.8.0 or newer, works under Remote-WSL and Remote-SSH, and never offers skip-permissions mode.
- **`backend = "auto"` works outside herdr and tmux.** From a plain terminal, an editor, cron or systemd, with tmux installed, the sessions run in the detached tmux session `igris-<project>`.
- **Start part of a phase from the TUI.** The start wizard has a **Tasks** step (All tasks · Only… · From… · Until…), and the end-of-run summary offers **Arise W17…**, so the next phase starts without leaving the TUI.
- **Open session goes where the session lives.** From any session on the run's tmux server `o` switches to the task's window; from elsewhere the card says where the session is, and `y` copies the command.
- Fixed: commits are counted as kept, not as made, after a rerun in a parallel phase.
- Fixed: the usage hold counts down to the time igris resumes, not the window's reset.
- Fixed: a run's own question is not a task in "N tasks need you" (`1 task and the run need you`).
- Fixed: the budget line is current at a sequential task's commit question.
- Fixed: Raise on a budget reached says what the budget has used by now, not when it was reached.
- Fixed: the end-of-run summary no longer cuts the price estimate off the tokens line.

## Upgrade

Install the new igris and you are done: nothing in your plan, `igris.toml`, scripts or `.igris/` needs to change, and a run interrupted under 1.8 resumes. `igris update` does it for you. Stop a run (`igris stop`) before you update the igris that is hosting it. From 0.x, run `igris config migrate` once in each project first; see the [upgrade guide](https://drilonrecica.github.io/igris/docs/upgrade.html).

Homebrew:

```sh
brew upgrade igris                         # or: brew install drilonrecica/tap/igris
```

Or `go install github.com/drilonrecica/igris/cmd/igris@v1.9.0`, or download the archive for your platform below, with `checksums.txt` and `checksums.txt.sig`, and verify them:

```sh
curl -fsSLO https://raw.githubusercontent.com/drilonrecica/igris/v1.9.0/allowed_signers
ssh-keygen -Y verify -f allowed_signers -I igris -n file -s checksums.txt.sig < checksums.txt
sha256sum --ignore-missing -c checksums.txt    # macOS: shasum -a 256 --ignore-missing -c checksums.txt
tar xzf igris_1.9.0_<os>_<arch>.tar.gz
install -m 755 igris ~/.local/bin/igris
igris version
```

The first command must print `Good "file" signature for igris`.

The extension: install `drilonrecica.igris` from your editor's extension view, or `code --install-extension igris-1.9.0.vsix` with the file attached below.
